1. What is an IP Address?

Answer : An IP Address is a unique number assigned to a device on a network. It helps devices identify and communicate with each other.

2. What is a MAC Address?

Answer : A MAC Address is a unique hardware address assigned to a network adapter by the manufacturer.

3. What is a Default Gateway?

Answer : A Default Gateway is the router that forwards data from your local network to other networks such as the internet.

4. What is DNS?

Answer : DNS (Domain Name System) converts website names like google.com into IP addresses that computers can understand.

5. Difference Between Public and Private IP
Answer:

Public IP	
Used on the Internet	
Assigned by ISP	
Unique globally	
Example: 49.x.x.x	

Private IP
Used inside local networks
Assigned by Router
Can be reused
Example: 192.168.x.x
